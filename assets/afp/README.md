# 网易云音频指纹组件

完整的网易云识别需要自行提供有权使用的 `afp.js` 和 `afp.wasm.js`。两者不在公开仓库和下载包中，也不受本项目原创代码许可覆盖。

已下载公开包的用户：将两个文件放到 `lysia.exe` 同级的 `plugins/netease/`，重新启动软件即可启用网易云。软件优先加载这些本地文件，再尝试构建内置资源；只放置自己信任且有权使用的组件，它们会作为代码运行。没有组件时酷狗仍可正常识别，可在设置中选择酷狗来避免缺失提示。

开发者：有权使用的文件也可放在本目录供本机构建。`tool/build_windows.ps1 -PublicRelease` 可在不提供这些文件的情况下构建公开包，并将它们排除出构建目录；普通构建会检查文件是否齐全。
