聆汐 · Lysia  v0.2.0（Windows x64）

解压整个文件夹，双击 lysia.exe。请保留旁边的 DLL 和 data 文件夹。

使用
1. 播放电脑上的音乐，点击“开启自动识曲”；点击暂停即可停止。
2. “识别一次”只执行一轮系统声音识别。
3. “导入音频”支持 WAV、MP3、FLAC、OGG Vorbis、AAC、M4A、WMA。音频至少 3 秒；长文件截取一小段进行识别。OGG Opus 暂不支持。
4. 默认同时请求网易云与酷狗，可分别查看候选；设置中可调整间隔、识别平台和亚克力效果。
5. 关闭窗口后进入托盘；界面电源按钮或托盘退出菜单可彻底退出。

本地数据
历史和设置保存在 lysia.exe 同级的 lysia.sqlite。运行时可能产生 -wal、-shm 辅助文件，请勿在运行期间删除或单独搬动它们。
搬迁、备份前先彻底退出，再复制整个程序文件夹。请放在有写入权限的位置。
首次运行会复制旧版默认位置的数据，原数据库仍保留。WebView 缓存保存在程序目录的 cache 子目录。

运行条件与限制
需要联网识别；截取的音频或音频指纹会发送至所选平台。识别效果取决于音乐片段、曲库和接口状态。
需要 Microsoft Edge WebView2 Runtime；通常 Windows 已预装。
部分格式依赖 Windows 自带的媒体解码器；精简系统或 Windows N 版可能需要补齐媒体组件。
亚克力效果受 Windows 透明效果、远程桌面等环境影响，必要时可在设置中关闭。
当前交付 Windows 版本，Android 尚未完成。
